# Injection

A neon music player for the browser. An audio-reactive glowing orb pulses with your music while synced lyrics float over it.

injection-wheat.vercel.app

## Features

- Audio-reactive orb drawn on a canvas with the Web Audio API
- Synced lyrics that float and fade line by line
- Automatic lyrics lookup through [LRCLIB](https://lrclib.net), or load your own `.lrc` file
- Playlist with previous, next and shuffle
- Songs and lyrics are saved in your browser, so you only add them once

## Run it

1. Click **Add songs** or drag audio files onto the page.
2. Lyrics are searched automatically. Edit the search box and click **Find lyrics** if it picks the wrong song.

## Notes

- Lyrics are fetched from LRCLIB, so that part needs an internet connection.
